# 姜小妹分类影视搜索

影视搜索按命令分类强过滤；命令后必须是 ASCII 空格或 Tab：

```text
短剧 剧名
电视剧 剧名
电影 片名
动漫 名称
综艺 名称
剧 名称
```

`短剧` 接受短剧及 AI 漫剧分类；`电视剧` 接受电视剧、连续剧及国产剧、港剧、日剧等电视分类；`电影` 只接受电影/影片分类；`动漫` 只接受动漫、动画、卡通和番剧分类；`综艺` 只接受综艺、真人秀和脱口秀分类。`剧 名称` 是不做分类过滤的通用搜索，可以命中上述全部分类、体育及其他未知分类。分类命令会在标题评分、模糊匹配和版本缓存之前过滤类型，不会因为同名混入卡片。

例如 `电视剧 三国演义` 会并发查询多个苹果 CMS/VOD JSON 源，只在电视分类中选择结果，然后通过 OneBot `wechat_link_card` 消息段发送微信链接卡片。`电视剧三国演义`、`/电视剧 三国演义` 和使用全角空格的消息不会触发。

精确发送 `剧` 会直接输出按分类搜索、体育回放、最新推荐、选集与版本分组的图标文本帮助，不跳转网页。

精确发送以下命令可获取最新短剧推荐：

```text
短剧推荐
```

只有消息完全等于 `短剧推荐` 才会触发；前后空格、命令前缀或额外文字均不匹配。插件从实时资源站最近条目中筛选有 HLS 播放地址的短剧及 AI 漫剧分类，跨源去重并按更新时间倒序取最新 12 部。机器人发送一张推荐卡片，点击进入带封面的中间页；页面展示年份、分类、集数和来源，点击任一作品直接进入播放器。推荐结果缓存 10 分钟，卡片和中间页均不嵌入 m3u8 地址；公网中间页不可用时降级为12行剧名。

推荐卡片固定使用推荐列表第 1 部作品的封面，不会借用后续作品封面。资源站返回 WebP、AVIF 等格式时，插件会经播放器域名生成短期 JPEG 封面地址，避免微信退化为通用链接图标；只有这张小封面经过服务器，视频流仍由播放源直连。

## 群聊定时推荐

插件页面“影视定时推荐”可以为指定群聊 UMO 创建主动推送任务。支持短剧（含 AI 漫剧）、电视剧、电影、动漫、综艺、体育回放和全部分类；可设置任务名称、每天或指定星期、发送时间、每次 6-20 部、启用状态。任务保存在 `data/plugin_data/jiang_short_drama/recommendation_schedules.json`，保存、启停和删除后会立即同步 AstrBot Cron，无需重启。

每张任务卡片提供“立即测试”，会立刻向目标群发送一次最新推荐卡片，但不会改变原定执行时间。群聊 UMO 格式例如：

```text
aiocqhttp:GroupMessage:51632940287@chatroom
```

资源选择遵循以下顺序：

1. 有精准同名结果时，只在精准结果里选择，不混入续作或“第二季”。
2. 精准结果为空时，才启用达到最低分数的模糊匹配。
3. 对单线路 m3u8 解析实际总时长（包括 master playlist 的子清单），优先选择时长最长且达到 `full_version_min_minutes` 的完整版。
4. 没有完整版时回退到集数更完整的分集源。

普通播放卡片使用精简排版：标题仅显示“剧名｜当前集/完整版”，描述仅保留年份、类型、总集数或时长和“点击播放”。多版本卡片显示“剧名｜N个版本”，摘要只预览去重并排序后的年份和“点击选择版本”。资源站名称、选集说明、详细类型及其他版本命令不再堆入卡片摘要，相关功能仍保留在播放器和版本选择页中。

遇到《三国演义》这类同名不同版本的内容时，普通搜索会自动发送一张“多个版本”卡片。点击卡片进入带封面的版本选择页，每个版本展示实际资源名、年份、类型、集数、主要演员和来源；点击对应封面或卡片后直接进入该版本的播放器。

插件会按标题、年份、媒介类型及主演合并不同资源站的重复版本，并过滤解说、预告和花絮。搜索阶段顺带生成版本候选，不会为了判断多版本再请求一遍所有资源站。仍可显式发送：

```text
电视剧 三国演义 版本
```

机器人会发送同一张版本选择卡片；如果公网版本页不可用，则降级为文字列表。随后仍可按列表编号直接播放，例如：

```text
电视剧 三国演义 版本2
```

版本列表缓存 10 分钟，因此查看列表后再选择编号时顺序保持一致。版本页和播放页均使用短期随机令牌，不在微信卡片 URL 中嵌入 m3u8 地址。

## 体育比赛回放

体育使用独立命令，`体育` 后必须有 ASCII 空格或 Tab 和查询词。单独发送 `体育`、`体育足球`、`/体育 足球` 或使用全角空格都不会触发。体育分类或联赛名称会进入赛事集合页，年份可选，例如：

```text
体育 斯诺克
体育 足球
体育 CBA2023
体育 NBA2024
体育 英超2025
```

当前识别篮球、足球、斯诺克、台球、网球、羽毛球、乒乓球、排球、F1、UFC、WWE，以及 CBA、NBA、WNBA、NCAA、浙BA、英超、西甲、德甲、意甲、法甲、欧冠、中超、中甲、亚冠、世界杯、欧洲杯、美洲杯、奥运会和亚运会。插件同时校验标题关键词和资源站体育分类；带年份时再校验年份，因此《我爱斯诺克》《足球爸爸》《足球教练》等同名影视不会混入回放。

赛事结果不会一次性加载全部：机器人先发送一张赛事回放卡片，中间页立即使用已缓存的第一页；封面使用浏览器原生懒加载，接近页面底部时才请求下一页。用户可以持续向下浏览全部可用页面，也可点击“加载更多”；空白页不会自动连续翻页，避免在微信中一次请求几十乃至上百页。不同资源站及前后页的同名回放会去重。

点击任意回放后，服务端把集合令牌转换为该场回放的播放令牌，再进入原有播放器；微信卡片和集合页都不会携带 m3u8 地址。集合页无法使用时降级为最新 20 场纯文字列表。

如果用户在 `体育 ` 后粘贴资源站中的完整赛事名称，插件会要求标题完全一致，并再次校验资源分类确属体育；命中后不进入集合页，直接发送该场赛事的可播放卡片。部分标题或近似标题不会误触发直达，以免把同名影视当作比赛回放。

模糊匹配不是只给首次结果打分：精准同名为空时，插件还会使用安全的缩短词和已知近形/别名做第二轮资源站查询，再用原始输入复核相似度及媒体分类。例如 `短剧 全球杀机` 会二次查询 `全球杀戮`，但仍只接受短剧分类。两字短词不会拆成单字扩搜，避免把 `腊肉` 错配成体育视频中的“老腊肉队”；能识别可能名称但对应分类尚未收录时，会明确提示暂无可播放资源。

需要指定分集时使用：

```text
电视剧 剧名 第12集
```

插件同时支持 `第1-20集` 这类合并线路，会自动把第 12 集映射到对应播放段，不会一次发送几十张卡片。

## 播放器内选集

插件内置了分集播放器。配置公网入口后，分集卡片会打开同一个播放页，并提供：

- 竖屏页面在播放器下方以五列网格完整铺开全部剧集，不使用横向滑动；
- 自定义可关闭的底部选集面板，不调用 Android 原生全屏下拉框；
- 播放画面左右两侧的小型上一集、下一集图标；
- 播放画面左上角固定显示“选集”，顶部正中显示当前集数；
- 自定义播放器容器全屏按钮固定在右上角，与清晰度按钮组成紧凑按钮组，不遮挡浏览器原生控制栏；进入全屏后仍保留上下集、集数、横屏选集面板和清晰度控件；
- 播放过程中长按视频画面约 350 毫秒可临时 2 倍速播放，松手恢复长按前倍速；左上角选集按钮下方短暂显示半透明 `2×` 小标记并在约 1.2 秒后自动隐藏，不遮挡主体画面；底部原生控制栏区域不触发，避免拖动进度条时误操作；
- 桌面和手机端都将标题、播放器及播放状态作为首屏区域水平、垂直居中；手机端使用微信内置浏览器的实际可见高度动态计算，地址栏伸缩、刘海安全区及横竖屏切换后会自动重新居中，选集继续排列在播放器下方；
- 播放器右上角清晰度菜单：多码率 master playlist 可选择自动、480P、720P、1080P 等，单码率线路显示“原画”；
- 按视频真实宽高动态布局，横屏铺满可用宽度，竖屏居中并限制到视口高度；
- 播放失败时提供紧凑的当前集重试；
- 本集播完自动播放下一集；
- 按“剧名 + 资源来源 + 封面”在用户当前浏览器本地记住当前集和各集播放进度；重新搜索、从版本页或推荐页再次打开同一资源也会续播。明确发送“第N集”时以指定集数为准；播放到结尾会清除该集进度。记录不会上传服务器，也不会在不同手机、浏览器或清除微信网页缓存后同步；
- 任一影视分类命令都可追加 `第N集`，例如 `电视剧 剧名 第12集` 会直接从播放器第 12 集打开。

播放列表使用短期随机令牌保存在机器人内存中，不会把几十个 m3u8 地址塞进微信卡片 URL。默认有效期为 6 小时，插件重载或 AstrBot 退出后旧令牌也会失效，重新发送搜索命令即可生成新卡片。

播放器默认只监听 `127.0.0.1:6197`。要让其他微信用户访问，需要把该端口通过 Nginx、Caddy、SSH 反向隧道等方式暴露为公网 HTTPS 地址，再配置：

```json
{
  "episode_player_public_base_url": "https://player.example",
  "episode_player_bind_host": "127.0.0.1",
  "episode_player_port": 6197
}
```

反向代理需要原样转发 `/short-drama/` 路径到 `http://127.0.0.1:6197`。例如 Nginx：

```nginx
location /short-drama/ {
    proxy_pass http://127.0.0.1:6197;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-Proto $scheme;
}
```

没有配置 `episode_player_public_base_url`、监听失败或搜索到的资源只有一个播放线路时，插件自动回退到原有单集公共播放器；微信卡片不会因此失效。

当前项目已部署为 `https://player.xiuxianjyj.xin`：VPS 上的独立 Nginx 站点通过 SSH 反向 Unix Socket `/run/short-drama-player.sock` 连接机器人本机 `127.0.0.1:6197`，不开放额外公网 TCP 端口，也不会改动 `xiuxianjyj.xin` 的 NewAPI 根站点。相关文件位于 `deploy/nginx/short_drama_player.conf` 和 `scripts/start_short_drama_reverse_tunnel.ps1`；Windows 当前用户登录时会隐藏启动隧道，断线后每 10 秒自动重连。

卡片默认打开 `m3u8-player.cc` 的 HTTPS HLS 播放页，再由页面加载第一集 m3u8，避免微信把资源站域名当作顶层网页拦截。目标源仍需允许浏览器跨域访问；插件烟测所用源返回了 `Access-Control-Allow-Origin: *`。

若部署了自己的公网 HTTPS HLS 播放页，可在插件配置中替换 `player_url_template`，例如：

```text
https://player.example/watch?url={url}&title={title}&episode={episode}
```

三个占位符都会经过 URL 编码。单个资源站超时或返回异常时会自动忽略，不影响其余来源。

只有明确把模板设置为 `direct` 时，卡片才会重新直达 m3u8；该模式可能触发微信安全页拦截。
